# Managing Alerts

The **Alerts** section allows administrators to configure and monitor system alerts such as reminders and scheduled reports.

![[alerts_page_overview.png]]

### Alerts Overview

At the top of the **Alerts** page, administrators can view summary information displayed in cards:

- **Total Alerts** – The total number of alerts configured in the system.
    
- **Active Alerts** – The number of currently active alerts.
    
- **Daily Alerts(Is Daily Run)** – The number of alerts scheduled to run daily.
    

### Search and Filter

Below the summary cards, a **Search and Filter** section allows administrators to:

- Search alerts by name or keyword.
	
- Search alerts by provider name.
    
- Apply filters such as:
	- Active
	- Inactive

### Alerts List

The alerts list displays all configured alerts in a table format, typically including:

- **Alert Name**
    
- **Description**
    
- **Instance Provider**
    
- **Notify Before (Days)**
	
- **Status** (Active/Inactive)
    
- **Created At**
    
- **Actions** (e.g. Edit, or Delete)
    

This view helps administrators manage and maintain system-wide alert settings effectively.

## Creating a New Alert

To configure a new alert in CLM, follow these steps:

### 1. Navigate to the Alerts Page

From the sidebar menu, select **Alerts**.

On the top-right corner of the page, click the **Add Alert** button.

![[alerts_dashboard_Add.png]]
### 2. Fill in the Alert Form

A form will open with the following fields:

- **Alert Name** – Enter a unique name for the alert.
    
- **Description** – Provide a short description of the alert.
    
- **Instance Provider (Dropdown)** – Select the instance/provider associated with this alert.
    
- **Notify Before (Days)** – Specify the number of days before the event or expiry when the alert should be triggered.
	
- Daily Send Time – Specify the time of day to send daily alerts (HH:MM).
	
- Notification emails – Enter the email addresses to receive alerts (maximum of 5).
    
- **Status (Dropdown)** – Choose whether the alert is Active or Inactive. 
    

### 3. Save the Alert

After completing the form, click the **Create** button.

### 4. Post-Creation

The new alert will appear in the **Alerts List**.  
Administrators can manage the alert by viewing, editing, disabling, or deleting it as needed.
